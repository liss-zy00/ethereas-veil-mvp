# Etherea's Veil (MVP)

Jogo narrativo feito em GameMaker. Neriah conduz a conversa e o jogador escolhe cartas
(Curiosidade, Dúvida, Esperança). As escolhas levam a um de três finais.

## O que tem

- Telas de abertura e menu com nuvens e sol em parallax
- Opções: tela cheia, idioma (inglês ou português), volume da música e dos efeitos
- Diálogos escritos em Yarn (`datafiles/english.yarn` e `datafiles/portuguese.yarn`), rodados pelo Chatterbox
- Texto com efeitos pelo Scribble

## Abrir o projeto

1. Instale o GameMaker 2024.6 ou mais novo.
2. No Windows, clone com caminhos longos ligados:
   `git clone -c core.longpaths=true https://github.com/liss-zy00/ethereas-veil-mvp.git`
3. Abra `Etherea's Veil - MVP.yyp`.
